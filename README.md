# Mbank Logs Downloader
Terminalowa aplikacja pozwalająca na wygodne i sprawne pobieranie logów ze środowisk mbanku.

## Uruchomienie
Instalacja modułów js
```
yarn install
```

Uruchomienie aplikacji
```
yarn start
```

## Instrukcja obsługi
Po uruchomieniu aplikacji mamy do wyboru kolejne katalogi, do których możemy nawigować.
Jeżeli nasz wybór padnie na plik zostanie on pobrany do katalogu logs w katalogu projektu.
